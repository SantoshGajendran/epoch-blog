When serving models with variable-length sequences, PyTorch's native caching allocator can cause virtual memory fragmentation leading to unexpected CUDA Out of Memory (OOM) errors even when physical memory is available. Setting `expandable_segments:True` allows PyTorch to allocate memory in virtual contiguous chunks, mitigating fragmentation overhead.
